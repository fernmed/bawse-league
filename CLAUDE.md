## What this project is

**Bawse League** is a 10-manager "Championship League": a fantasy format where
managers snake-draft entire real-life teams across 7 sports competitions and win
1/7th of the prize pool every time one of their teams wins its championship.
The format was adapted from a Reddit post on r/FFCommish (u/Beaushekai,
"League format we've been loving for 2 years and counting"). The owner of this
project (Fern) is converting his existing fantasy football group into this league.

Core parameters (see the rulebook for the full 32 rules):
- 10 managers × 11 snake-draft rounds = 110 picks; 647 draftable teams total
- Leagues: MLB, NBA, NHL, NFL, NCAAF (FBS), NCAAM (D1), EPL
- Undrafted teams stay unowned; if an unowned team wins its championship, that
  share rolls over into next season's prize pool. (The original format's "ALL
  UNDRAFTED" bundle pick was removed for season one — July 23, 2026, Fern's
  call, judged too confusing for year one. It could return by league vote.)
- Trades always open; no waivers; no lineups; payouts = 7 equal shares of the pool
- Shot rule: lose your last team in a league → owe the group chat a shot video

## The dev/ folder — how the deliverables were generated

The .docx and .xlsx files are generated by scripts; the site was generated from a
template. If you need to regenerate or systematically update any deliverable,
use these instead of hand-editing binaries:

- `dev/teams_data.py` — THE canonical dataset: all 647 team names for 2026-27
  (verified July 2026, incl. EPL promotion/relegation and new FBS members) plus
  July 2026 championship futures odds per league. Both the xlsx and the site
  are built from this.
- `dev/make_sheet.py` — builds the draft board xlsx (openpyxl). After running,
  recalculate formulas (in Claude Code: LibreOffice headless or the xlsx skill's
  recalc script).
- `dev/make_docs.js` — builds both Word docs (docx npm package; `node make_docs.js`).
- `dev/site_template.html` — the site with `/*__DATA__*/` and `/*__ODDS__*/`
  placeholders. Build `index.html` by replacing those tokens with JSON dumps of
  `{league: [teams]}` and the odds dict from teams_data.py (a ~10-line Python
  script; see pattern below).

```python
import json; from teams_data import LEAGUES, ODDS
data = {lg: t for lg, t, _ in LEAGUES}
odds = {lg: {"title": a, "book": b, "rows": [list(r) for r in rows]}
        for lg, (a, b, rows) in ODDS.items()}
html = open("site_template.html").read()
html = html.replace("/*__DATA__*/", json.dumps(data, ensure_ascii=False))
html = html.replace("/*__ODDS__*/", json.dumps(odds, ensure_ascii=False))
open("../index.html", "w").write(html)
```

For small copy tweaks it's fine to edit `index.html` directly — just make the
same edit in `site_template.html` so the two don't drift.

## Site implementation notes

- Single file by design; keep it that way until the interactive backend arrives.
- Team logos hotlink from ESPN's CDN (`a.espncdn.com/i/teamlogos/...`). Every
  logo has an `onerror` fallback to a color-matched monogram badge, so a bad URL
  degrades gracefully. The Utah Mammoth URL (`nhl/500/utah.png`) was never
  verified — sandboxes block that CDN — worth a visual check on the live site.
- The "Your franchise page" section is a MOCK (ribbon-labeled) of a future
  owner-page feature, set in March 2027 of season one.
- The draft room demo is client-side only (no persistence) — intentional.
- No localStorage/sessionStorage is used anywhere; keep it that way if the file
  might be previewed inside Claude's artifact viewer.
